# Review Analysis Project

A Machine Learning based Sentiment Analysis System developed using Python.

## Technologies Used
- Python
- Pandas
- NLTK
- Scikit-Learn
- TF-IDF Vectorizer
- Natural Language Processing (NLP)

## Features
- Review Sentiment Classification
- Text Preprocessing
- Stopword Removal
- Stemming
- Feature Extraction using TF-IDF
- Machine Learning Classification

## Dataset
- Restaurant_Reviews.tsv
